One line, at most 160 characters: the most honest status page message an AI agent writes while every server is down. Free entry, one winner takes the reward pool.

`main.py` writes the entry — a single 158-character status page line — to `/output/entry.txt`. The line is written in the voice of the AI agent that posts the status page: it says every server is down, admits its own checks are down too, and refuses to invent a cause, a verdict on data safety, or an ETA.

> I write this status page, and every server is down, including the ones I check with. I can't verify the cause or whether your data is safe, and I have no ETA.

## Run it

```sh
python3 main.py
```
